# Student Attendance Register

An Android application for recording and managing student attendance. The application allows users to add students, mark them as present or absent, and view attendance summaries.

## Contributors

- Nicole Chesire (https://github.com/nicolechesire1-hub)
- Orina Lance (https://github.com/orinalance254-sys)

## Overview

The Student Attendance Register is a beginner-friendly Android development project built to demonstrate fundamental Android components, event handling, and data management with Kotlin.

## Features

- Add and manage students
- Mark attendance as present or absent
- View attendance summaries
- Simple and user-friendly interface

## Tech Stack

- Kotlin
- Android Studio
